# staybnb

Modern, fully interactive Airbnb-style stays search experience for Bali.

## What's new (v2)

- **Tailwind CSS** for rapid modern styling
- **Lucide Icons** – clean, consistent SVG icon system
- Smooth **CSS animations** (card entrance, modal scale, heart pop, image zoom)
- Proper **modals**:
  - Listing detail + Reserve
  - Price range filter
  - Type of place
  - Become a Host
  - Account / Menu
- Interactive **Leaflet map** with animated markers
- Wishlist with localStorage + toast notifications
- Guest counter & date picker popups
- Fully responsive + mobile map FAB

## Tech

- Vanilla JS (no build step)
- Tailwind CSS (CDN)
- Lucide Icons
- Leaflet + Carto tiles
- Unsplash images

## Run locally

```bash
# Just open
open index.html

# or serve
npx serve .
```
